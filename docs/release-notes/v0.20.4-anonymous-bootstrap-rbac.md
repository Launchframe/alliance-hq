## Working notes

- **PR #504 — Anonymous bootstrap RBAC:** Sessions minted by `/api/auth/bootstrap` have no `hqUserId`; the legacy allow-all branch let them pass `requirePlatformMaintainer` and other permission guards. Deny all RBAC when `hqUserId` is null.

## Summary

- **Security** — Anonymous bootstrap sessions can no longer access admin or other permission-gated APIs; all RBAC checks fail closed when no HQ user is bound to the session.
