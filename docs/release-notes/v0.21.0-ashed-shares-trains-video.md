## Summary

**Ashed credential sharing**

- **Delegate Ashed access** — Owners share named-officer credentials with a capability whitelist (roster, video OCR, data management). Delegates accept via pairing; shares expire, revoke, and extend from current expiry (7-day cap).
- **Emails & digest** — Invite/accept/reject/revoke/expire emails plus an owner daily digest of delegate usage.

**Trains**

- **Welcome tour** — Interactive sandbox tour of the redesigned hub (week/day paint, focus mode, spin) without saving tour clicks.
- **Pool restore** — Undo an accidental new rotation from Eligibility when the current and prior generations do not overlap.
- **Pick & lock** — Pick Conductor stays available until lock; Spin again on unlocked drafts; lock confirm inline; Discord announce only for today's lock (or copy/quiet).
- **Fairer rolls** — R3/R4+ pools use current roster rank; day-scoped exclusions so re-spins do not redraw the same member; conductor minimums use Ashed VS totals.
- **Discord channels** — Train settings show server/channel names and can revoke a guild's train channel from HQ.

**Video review**

- **Issue nav & ghosts** — Jump prev/next across problem rows; scroll-bleed score ghosts cluster and auto-discard.
- **VS rank** — The # column follows in-game score order, not table row index.
- **Shadow reprocess** — Reprocess uses the primary archived video when the original upload object is gone.

**Also**

- Browser tabs show alliance tag, Admin, or video-job context.

## Breaking changes

- None for operators. Credential sharing is opt-in from Team settings.
