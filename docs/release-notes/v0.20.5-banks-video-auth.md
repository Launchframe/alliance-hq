## Summary

**Banks**

- **Lifecycle tabs** — Active, Dropping Soon, and Abandoned banks with explicit abandoned state; pending deposit-slip video reviews surfaced per stronghold.
- **City List review** — Split-screen screenshot preview and a 3-column mobile grid; banks sorted by level and deposit count.

**Video review**

- **Settings & row numbers** — Deposit-slip review settings dialog (sort, interpolation); read-only row numbers on VS and storm reviews to align with video frames.
- **Desert Storm** — Team A/B submits no longer wipe scores; Data Management lists scores by date with Team A/B badges.
- **Scene extraction** — Opening and closing frames captured at 50ms from each end for more accurate leaderboard pins.
- **Survey** — Multiple-choice steps auto-advance on tap.

**Auth & Discord**

- **Session hardening** — API routes require an existing session cookie (no lazy anonymous mint); extends the v0.20.4 bootstrap RBAC fix.
- **Discord auditability** — `/set-*` channel and conductor commands reply in-channel.

## Breaking changes

- **API auth** — Unauthenticated API requests without a session cookie now receive `401` instead of silently creating an anonymous session. Clients must call `/api/auth/bootstrap` or sign in first.
