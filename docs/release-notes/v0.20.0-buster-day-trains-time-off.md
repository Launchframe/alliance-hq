## Summary

**Buster Day**

- **Efficiency wizard** — Upload Friday roster + Sunday kills snapshots, then see a ranked Buster Day efficiency report (net VS vs power lost per commander).

**Time-off**

- **Alliance calendar** — Plan time off on the web calendar or via Discord `/my-time-off`; officers can check `/is-ally-offline` for ally availability.

**Trains**

- **Conductor history import** — Paste past conductor lists at `/trains/history-import` with roster matching and gap remediation.
- **Roster sync wizard** — Simple Mode prompts officers to refresh the roster before spinning when the pool is empty or stale.
- **Day vs week picks** — Change today's mechanism without overwriting the whole week; lock before VIP; share a celebratory PNG after a spin.
- **Conductor reliability** — Prior-day VS wheels exclude weekly totals; Top VS uses the active roster; depleting pools survive swap/unlock; Saturday takedown uses with-replacement PIR.

**Onboarding & Discord**

- **Cross-server commanders** — Honor-system home-server prompt instead of a hard block when your game position differs from your alliance server.
- **`/who-is`** — Look up which commander a Discord user is linked to (and vice versa).

**Also in this release**

- Sidebar light/dark theme toggle, bank falloff My alliance filter, roster OCR v2 (rank headers + Members page), VR institute-level anomaly gap, and donation bulk `amount` fix for Ashed.

## Breaking changes

- None for operators. Trains Simple Mode adds a roster-sync step when the conductor pool needs attention.
